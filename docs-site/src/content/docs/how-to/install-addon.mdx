BlenderMCP installs from its own extension repository, so Blender downloads the right build for your computer and tells you when a new version is out. It needs **Blender 4.2 or newer**. On an older Blender, upgrade Blender first; 4.2 LTS and every release since work.

## Install from the repository

You're done when the BlenderMCP panel reads **Connected · Personal** (step 11).

<Aside type="note">
The download is about 22 to 27 MB, depending on your platform, because it bundles the Python packages the add-on needs. The repository publishes a separate build for Windows, macOS (Apple silicon and Intel) and Linux (x64 and ARM), and Blender picks yours, so nothing else needs installing.
</Aside>

## What to do next

- **Chat from the sidebar.** The Chat panel sits in the same BlenderMCP tab, below the connection status. Type a request and Claude works on the scene you have open. See [Chat inside Blender](/how-to/chat-in-blender/).
- **Connect another MCP client.** Claude Desktop, Claude Code or any MCP client can use the Blender you just connected. The [Quickstart](/tutorials/quickstart/) walks through the first one.

## Updating

When a new version is published, an **Update to** button naming it appears at the top of the BlenderMCP panel. Click it and the add-on downloads the build for your platform, showing a progress bar with a Cancel button in the panel and in Blender's status bar. Once the download matches the repository's checksum, Blender installs it in about a second, reloads the add-on, and it reconnects on its own from your saved login. The status bar says **Updated to** the new version, and no restart is needed. If the repository's cache is turned off or the download fails, Blender's own installer downloads it instead.

The same offer appears in `Preferences → Add-ons → Blender MCP` as a box reading, for example, `Addon update available: 2026.930.1 → 2026.930.2`, with an **Update now** button.

You can also update the usual way: `Preferences → Get Extensions → Check for Updates`, then `Update` beside Blender MCP.

The one-click button needs online access turned on in Blender (it offers to turn it on) and works from 2026.926.7 onward. Versions 2026.926.0 to 2026.926.6 had an Update now button that could crash Blender, so the server no longer offers them the update; update those through `Get Extensions` instead.

<Aside type="tip">
Versions are calendar-based, `YYYY.MDD.N`: `2026.930.2` is the third release on September 30, 2026. Releases before the switch used `1.5.x`.
</Aside>

## Moving from an older file-based install

Early versions of BlenderMCP installed as a single file through `Preferences → Add-ons → Install`. If yours did, the panel offers **Get** and the version number instead of Update to, and it opens this page, because installing from the repository on top would leave two copies side by side. Move over once:

<Steps>

1. Open `Edit → Preferences → Add-ons`, find **Blender MCP**, expand it, and click `Remove`.

2. Restart Blender.

3. Follow [Install from the repository](#install-from-the-repository) above, including the login. The old install kept its login in its own preferences, so you sign in once more.

</Steps>

From then on, updates arrive through the Update to button.
