BlenderMCP links the Blender on your desk to a hosted server at `https://mcp.blender.bet/`. Once they're connected, Claude (or any other MCP client) can look at your scene, build and change objects, set up materials and cameras, and render, all in the Blender you're watching. Several clients, and several people, can work on the same scene at once. Each account gets its own private connection, so nobody else sees your Blender.

The add-on installs from Blender's own extension manager. Add `https://mcp.blender.bet/install` as a repository once, and Blender keeps it up to date from then on.

## Two ways to work

<CardGrid>
  <Card title="From your MCP client" icon="laptop">
    Add `https://mcp.blender.bet/` to Claude Code, Claude Desktop, claude.ai, or another MCP client, then ask for what you want. The client calls tools that run inside your Blender and report back.
  </Card>
  <Card title="From the Chat panel" icon="comment-alt">
    The **Chat** panel sits in the BlenderMCP sidebar tab, below the connection status. Type a request and the reply streams in while the assistant works. Before it runs Python, it shows the code with **Allow** and **Deny**.
  </Card>
</CardGrid>

On mcp.blender.bet, Chat answers with Claude Haiku 4.5 and can consult a stronger model when a request needs it, Claude Fable 5.1 unless you pick another under **Preferences › Chat backend › Escalate to**. Every change it makes to the scene is its own Ctrl+Z step, and **Undo last chat change** takes back everything from its last reply at once. The binder clip button next to the message field attaches your selection, what you see in the viewport, or a text block to the next message.
