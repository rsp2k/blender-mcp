By the end of this page, Claude will change your Blender scene while you watch. You'll add the Blender MCP extension to Blender, log in once through your browser, and type a request in Blender's own sidebar. Nothing else needs installing.

You need Blender 4.2 or newer and a web browser. Never used Blender? It's free and takes about ten minutes to install: [Get Blender](/tutorials/get-blender/) walks you through it.

## Install and log in

Do these in Blender. You're done when the BlenderMCP panel reads **Connected · Personal** (step 11).

## Ask Claude for a change

Below the connection status in the BlenderMCP tab is the **Chat** panel. New accounts start with a free trial, and the panel shows how much of it is left.

<div class="shot-single not-content">
  <img src="/img/chat/chat-trial-start.webp" width="245" height="238" alt="The Chat panel on a new account: the model button reading Claude Haiku 4.5 › Fable 5.1, a row reading 100% free left with a Use my own key button, a hint about asking for something in the scene, and the message field." />
</div>

Click the message field, type this, and press `Enter`:

```text
What's in my Blender scene?
```

Claude looks at your scene and describes what's there. On a fresh file that's the default cube, a camera and a light. Now ask for a change:

```text
Add a sphere next to the cube and make it orange.
```

Watch the viewport: the sphere appears and turns orange. Each change Claude makes is one `Ctrl+Z` step, and **Undo last chat change** takes back a whole reply at once. If Claude needs to run Python, the panel shows the code first and waits for **Allow** or **Deny**.

[Chat inside Blender](/how-to/chat-in-blender/) covers the rest: clipping objects to a message, the Reader, and choosing a model.

## When the free trial runs out

When the trial is used up, or any time you click **Use my own key**, the panel asks for a Claude API key:

<div class="shot-pair not-content">
  <figure>
    <img src="/img/chat/chat-key-box.webp" width="245" height="345" alt="The Chat panel with a box reading Paste your Claude API key to keep chatting, a password field, Get a key and Save key buttons, and a note that the key is sent once to the server and stored encrypted, never saved in Blender." />
    <figcaption>Paste a key to keep chatting.</figcaption>
  </figure>
  <figure>
    <img src="/img/chat/chat-key-refused.webp" width="245" height="160" alt="The same box after a mistyped key, with the message Anthropic didn't accept that key. Check it at platform.claude.com/settings/keys." />
    <figcaption>A key that doesn't work is turned away before it's saved.</figcaption>
  </figure>
</div>

<Steps>

1. Click **Get a key**. It opens **Settings › API keys** in the Claude Console. Sign in, or create an account if you don't have one, then click **Create key**. The Console shows the key, which starts with `sk-ant-`, only once, so copy it right away.

2. Paste the key into the field in the Chat panel and click **Save key**.

3. The server checks the key with Anthropic before saving it, then the box closes and you can carry on where you left off.

</Steps>

Your key is sent to the server once and stored there encrypted. It is never saved in Blender's preferences or your .blend file, and from then on your requests are billed to your Anthropic account. To remove it, open `Edit › Preferences › Add-ons › Blender MCP` and click **Clear backend** under **Chat backend**.

## Use Claude Code or Claude Desktop too (optional)

The same server works with other MCP clients, which helps when you'd rather drive Blender from the tools you already use. Your client connects to `https://mcp.blender.bet/`, exactly as written with no `/mcp` on the end, and signs in with the same account you used in Blender. The server only shows a client the Blenders logged in as the same person, so a different account finds nothing to talk to.

<Tabs syncKey="mcp-client">
<TabItem label="Claude Code">

```bash
claude mcp add --transport http blender https://mcp.blender.bet/
```

Start Claude Code, type `/mcp`, pick **blender**, and authenticate. Your browser opens the same sign-in page you saw from Blender.

</TabItem>
<TabItem label="Claude Desktop / claude.ai">

<Steps>

1. Open **Settings › Connectors** and click **Add custom connector**.

2. Name it `Blender` and enter `https://mcp.blender.bet/` as the URL.

3. Click **Connect** and sign in through the browser.

</Steps>

</TabItem>
</Tabs>

Then ask the same questions as above in that client. These clients use your own Claude plan, not the Chat panel's trial.
