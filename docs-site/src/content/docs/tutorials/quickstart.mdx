By the end of this page, Claude will read your Blender scene and change it while you watch. You'll add the Blender MCP extension to Blender, log in once through your browser, and point Claude at the hosted server. Nothing runs on your machine except Blender and the client you already use.

You need Blender 4.2 or newer, a web browser, and an MCP client such as Claude Code, Claude Desktop, or claude.ai. Never used Blender? It's free and takes about ten minutes to install: [Get Blender](/tutorials/get-blender/) walks you through it.

## Install and log in

Do these in Blender. You're done when the BlenderMCP panel reads **Connected · Personal** (step 11).

## Connect your MCP client

Your client connects to the same server as Blender. Use the root address `https://mcp.blender.bet/` exactly as written, with no `/mcp` on the end, and sign in with the same account you used in Blender. The server only shows a client the Blenders logged in as the same person, so a different account finds nothing to talk to.

<Tabs syncKey="mcp-client">
<TabItem label="Claude Code">

```bash
claude mcp add --transport http blender https://mcp.blender.bet/
```

Start Claude Code, type `/mcp`, pick **blender**, and authenticate. Your browser opens the same sign-in page you saw from Blender.

</TabItem>
<TabItem label="Claude Desktop / claude.ai">

<Steps>

1. Open **Settings › Connectors** and click **Add custom connector**.

2. Name it `Blender` and enter `https://mcp.blender.bet/` as the URL.

3. Click **Connect** and sign in through the browser.

</Steps>

</TabItem>
</Tabs>

## Your first request

Start a new conversation and ask:

```text
What's in my Blender scene?
```

Claude calls the server, the server asks your Blender, and the answer describes what's actually there. On a fresh file that's the default cube, a camera, and a light.

Now ask for a change:

```text
Add a sphere next to the cube and make it orange.
```

Watch the viewport. The sphere appears and takes on its new color. If you expand **Activity** under the BlenderMCP panel, it lists each command Claude ran, newest first.

<Aside type="tip" title="Prefer to stay in Blender?">
In the **BlenderMCP** tab, scroll to the **Chat** panel under the connection status, type the same request, and press the play button. A model does the work in the Blender you typed in, with no other client needed. Before it runs any Python, the panel shows the code with **Allow** and **Deny**. See [Chat inside Blender](/how-to/chat-in-blender/).
</Aside>

## What just happened

Blender and Claude both signed in to the same server as you. The server keeps a private bus for each account: your Blender joined it as a long-lived client and your Claude session joined as a short-lived one. Each Blender tool Claude called traveled over that bus to the add-on, ran inside Blender, and came back to Claude as an ordinary tool result. [How OAuth isolates buses](/explanation/oauth-buses/) has the details.
